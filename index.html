📖 GreenScan Quick Guide

Welcome to GreenScan 2.0! This interactive platform simulates centralized and federated transfer learning using MobileNetV3-Small on a 5-class waste dataset, while tracking real-time carbon footprints.

📂
1. Dataset Explorer
Inspect class count distribution and view dataset thumbnails. If you don't have images ready, click "⚡ Generate Synthetic Dataset" on the Dataset page to instantly create 100 color-coded samples.
🧠
2. Centralized Model Training
Configure training hyper-parameters and click "Start Training". Watch real-time loss and accuracy curves build dynamically through a WebSocket connection.
🔬
3. Model Learning Viewer (Grad-CAM)
Upload any waste image to see a Grad-CAM Heatmap explanation showing the precise activation patterns the model focused on.
🌐
4. Federated Learning Simulation
Launch multiple edge training clients concurrently (Node A, B, C) directly from the dashboard and watch weights aggregate.
📊
5. Comparative Reports
Compare centralized training efficiency with federated learning across carbon emissions, bandwidth usage, and validation accuracy. Download PDF/CSV/Excel reports.
